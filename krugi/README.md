# Кружки: Android-приложение

Трекер из кружков (серия с огоньком, заметки, выбор длины) в виде приложения для Android.
Внутри обычная страница в WebView, она работает без интернета, прогресс хранится на телефоне.

## Как получить APK (без Android Studio)

1. Зайдите на github.com и создайте новый репозиторий (кнопка **New**, название любое, например `krugi`).
2. Загрузите в него все файлы из этого архива: **Add file → Upload files**, перетащите содержимое папки.
   Папка `.github` скрытая. Если она не перетащилась, создайте файл вручную:
   **Add file → Create new file**, в имени введите `.github/workflows/build-apk.yml` и вставьте
   содержимое файла `build-apk.yml` из архива.
3. Откройте вкладку **Actions**. Сборка запустится сама (около 3–5 минут). Если нет, выберите **Build APK → Run workflow**.
4. Когда появится зелёная галочка, откройте раздел **Releases** справа на главной странице репозитория
   и скачайте `krugi.apk`. Он также лежит в самой сборке (Actions → запуск → Artifacts → `krugi-apk`, внутри zip).
5. Откройте скачанный файл на телефоне. Android попросит разрешить установку из этого источника, согласитесь.

Если репозиторий приватный, скачивать APK нужно, войдя в свой аккаунт GitHub на телефоне.

## Если сборка не прошла

Откройте красный запуск во вкладке Actions, раскройте шаг с ошибкой и пришлите мне текст ошибки.

## Заметки

- Это отладочная сборка (debug): для личного пользования подходит, в Google Play в таком виде её не выложить.
- Светлая и тёмная тема берутся из настроек телефона. Если нужно, переключите тему кнопкой в «Настройках» внутри приложения.
- Если нужно поменять трекер, замените файл `app/src/main/assets/index.html` и загрузите изменения в репозиторий: APK соберётся заново.
